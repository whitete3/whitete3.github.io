AWS NYC 311 Complaint Resolution Model

Built a cloud-based data science workflow using NYC 311 complaint data to predict whether service requests would be resolved within 3 days.

AWS S3 Athena Python pandas scikit-learn SQL
More details

Problem

City service data can help identify patterns in complaint resolution times. This project focused on predicting whether a 311 complaint would be resolved quickly.

Approach

Used AWS-based data storage and querying workflows, then trained a baseline logistic regression model using features such as agency, borough, problem type, zip code, day of week, and hour of day.

Results & Impact

The baseline model reached 88.0% accuracy, with strong precision and recall for quickly resolved complaints. The main limitation was class imbalance, since most complaints were resolved quickly.
